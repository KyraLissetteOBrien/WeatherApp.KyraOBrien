This is an up and coming weather application written in Kotlin for Android Studio. In its current phase 1 state, the UI is simple and clean, with a creature feature to change the font sizes - or +. In the future, this will be connected to an API, and is brainstormed to have a toggle for dark and light mode, and holiday themes for the current or next up.

Icons Resource: https://github.com/Makin-Things/weather-icons
